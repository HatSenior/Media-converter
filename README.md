# Media Forge — минималистичный медиаконвертер

Запустите файл **`Запустить.cmd`** двойным кликом.

Доступно:

- добавление через кнопку `+`, окно выбора или перетаскивание;
- автоматическое определение изображений, видео и аудио;
- действия автоматически меняются в зависимости от типа файлов;
- собственные минималистичные окна добавления и переименования;
- кастомные список файлов и строки выбора;
- удаление и переименование элементов;
- выбор конвертации, сжатия видео или извлечения аудио;
- выбор выходного формата и качества;
- реальная обработка через установленный FFmpeg;
- конвертация изображений, видео и аудио;
- сжатие видео в MP4 H.264, MP4 H.265, WebM и MKV;
- извлечение звука в MP3, WAV, FLAC и M4A;
- три режима качества и автоматическая защита от перезаписи файлов;
- отображение прогресса и автоматическое открытие папки результата.

Исходные файлы не изменяются. Все результаты сохраняются рядом с программой:
`ready convertation`.
